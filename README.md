

# 🌌 VIBE

> **A collection of real-world applications built entirely by AI — no human wrote a single line of code.**

---

## 🚀 About

**VIBE** is a repository of fully functional applications generated end-to-end by autonomous AI agents.

Every project here is:

* **Conceived**
* **Designed**
* **Implemented**

…by an advanced multi-agent system called **Yami's Orchestrator**.

---

## 🧠 Yami's Orchestrator

Yami's Orchestrator is a custom-built AI pipeline developed from scratch in **Python**, powered by locally running models via **Ollama**.

It is **not**:

* OpenClaw
* AutoGen
* CrewAI
* Any existing orchestration framework

Instead, it is a fully independent system where specialized agents collaborate to:

```text
Plan → Design → Code → Test → Ship
```

Each step is executed autonomously without human intervention.

---

## 📚 Project Source

Project ideas are sourced from the **App Ideas Collection by Florin Pop** —
a curated set of application challenges organized by difficulty.

This repository systematically works through those challenges, producing **fully functional applications** generated purely through AI collaboration.
