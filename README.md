vibe is a collection of real-world applications built entirely by AI — no human wrote a single line of code.

Every project in this repository was conceived, designed, and implemented by an autonomous multi-agent system called Yami's Orchestrator — a custom AI pipeline built in Python using locally-run Ollama models. This is not OpenClaw, AutoGen, CrewAI, or any other existing AI orchestration framework. Yami's Orchestrator is an independent, from-scratch solution where specialized agents collaborate to plan, write, test, and ship working software.

Project ideas are sourced from the App Ideas Collection by Florin Pop — a curated list of application challenges grouped by difficulty. This repository works through those challenges systematically, producing fully functional apps generated purely through AI agent collaboration.

What makes this different:

100% AI-generated code — no human edits, no copy-paste, no scaffolding tweaks
Powered by open-source local models via Ollama (no proprietary cloud AI)
Built on a custom orchestration engine created by Yami, purpose-built for this project
A living proof-of-concept that local AI agents can build real, usable software end-to-end
